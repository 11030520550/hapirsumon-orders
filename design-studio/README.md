# Design Studio: הפרסומון, Premium Editorial

סביבת עיצוב נפרדת מהמערכת הפעילה. היא לא נטענת מ־`index.html` של האתר ולא משנה אותו. כל הנתונים בה פיקטיביים.

## הפעלה

מתוך תיקיית ה־Repository:

```
node design-studio/serve.mjs
```

ואז פותחים בדפדפן: **http://127.0.0.1:8020/design-studio/**

- **השרת:** אין צורך בהתקנה. השרת (`serve.mjs`) לא משתמש בתלויות, ומגיש לקריאה בלבד את `design-studio/` ואת `assets/`. כך הסטודיו משתמש בגופן ובצילומים של הפרויקט.
- **פורט אחר:** `node design-studio/serve.mjs 8030`.
- **כתובות ישירות:** `#/home`, `#/login`, `#/sheets`, `#/system`, `#/photos`, `#/motion`.
- **תצוגת נייד:** הכפתור "נייד" בסרגל העליון, או ישירות `?bare=1#/home` בחלון צר (בלי הסרגל של הסטודיו).

## מה יש בפנים

| לשונית | מה רואים |
|---|---|
| **מערכת עיצוב** | צבע (כולל טבלת ניגודיות), טיפוגרפיה, מרווחים וקווים, כפתורים, שדות, בחירה וסינון, טבלה, סטטוסים, הודעות, חלונות ותפריטים, טעינה, ריק ושגיאה, עקרונות |
| **צילום** | ארבעת הצילומים המורשים הקיימים, עם הערכת התאמה, ומפרט לשמונה צילומים להפקה, כולל פרומפט לכל אחד (גם ב־`PHOTO-BRIEF.md`) |
| **התחברות** | לפי הפריים המאושר בפיגמה, עם מסגרת דקה אחת סביב הטופס (480px). סיסמה ריקה מדגימה שגיאה. |
| **בית** | ברכה, תאריך לועזי ועברי, צילום, כספי החודש עם ספירה, הגיליון הקרוב (מקטע לכל מודעה, ספירה לאחור), משימות |
| **בית · Editorial Split** (ניסוי) | גרסה נוספת למסך הבית, לצד V1 שלא השתנה: שלושה אזורים אנכיים, כמו בהדמיה: צילום בימין, עמודת נייר באמצע וניווט כחול משמאל. הצילום (4:3) מוצג במלואו, בלי חיתוך, מתיחה או פילטר. מתחתיו רצועת הגיליון הקרוב, והקו שמעל המשימות ממשיך את קו התחתית של הצילום. כספי החודש: שני נתונים מובילים, ושני הנתונים הנוספים נפתחים לפי בקשה. הגיליון הקרוב, ספירה לאחור ומשימות. מעבר בין הגרסאות בלשוניות "בית · V1" ו"בית · Editorial Split". |
| **גיליונות** | מסך תפעולי: סינון, חיפוש (`/`), שורה שנפתחת לרשימת המודעות, תפריט פעולות, מצב ריק |
| **תנועה** | הדגמה של כל אינטראקציה ומפרט הזמנים |

**הצילום של Editorial Split פרטי:** הוא נשמר ב־`design-studio/private/editorial-split.png` עד לבירור הזכויות. התיקייה `private/` מוחרגת ב־`.gitignore`, ולכן לא עולה ל־GitHub ולא לאתר. בלי הקובץ מוצג במקומו משטח ניטרלי. כדי להחליף את הצילום בקובץ המקורי ברזולוציה מלאה, שומרים אותו באותו שם.

המתג **"מקומות לצילום"** מראה היכן ישולבו הצילומים שעוד חסרים. כרגע זה במסך הגיליונות.

## מבנה

```
design-studio/
  index.html          מסגרת הסטודיו
  css/tokens.css      כל הטוקנים: צבע, טיפוגרפיה, מרווחים, קווים, תנועה
  css/components.css  הרכיבים המשותפים ומצביהם
  css/screens.css     מעטפת המוצר (ניווט), התחברות, בית, גיליונות
  css/studio.css      הסרגל של הסטודיו ודפי ההדגמה (לא חלק מהמוצר)
  js/data.js          נתוני דמה; התאריכים מחושבים מהיום
  js/studio.js        ניתוב, מסכים ואינטראקציות
  serve.mjs           שרת מקומי בלי תלויות
  PHOTO-BRIEF.md      בריף הצילום
```

**המשך עבודה:** מסך חדש הוא פונקציה `viewX()` + `bindX()` ב־`studio.js` שעוטפת את התוכן ב־`shell()`, ומשתמשת רק ברכיבים מ־`components.css`.

**מעבר למערכת הפעילה (אחרי אישור):** מעבירים את `tokens.css` ואת `components.css` כשכבה, ואת מבנה המסכים מסך אחר מסך. הלוגיקה העסקית לא משתנה.
