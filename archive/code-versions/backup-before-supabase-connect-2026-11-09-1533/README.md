# מודעת — ניהול הזמנות פרסום בעיתון

אתר מקומי בעברית לניהול לקוחות, הזמנות פרסום וסטטוסי תשלום. המידע נשמר ב־`localStorage` של הדפדפן במכשיר הנוכחי; אין שרת ואין סנכרון בין מכשירים.

## הפעלה

1. פתחו את `index.html` בדפדפן עדכני (Chrome, Edge או Firefox).
2. בפתיחה הראשונה יוצגו נתוני הדגמה. לאחר מכן השינויים נשמרים אוטומטית בדפדפן.
3. לחצו על **לקוח חדש** כדי להוסיף לקוח, ואז על **הזמנה חדשה** כדי ליצור הזמנה.
4. לחצו על **רשימת לקוחות** בתפריט כדי לצפות בלקוחות השמורים. אפשר לחפש לפי שם או טלפון, לפתוח פרטים או לערוך לקוח. **הוסף לקוח** פותח טופס נפרד, והרשימה מתעדכנת מיד לאחר השמירה.
5. בטבלת ההזמנות אפשר לחפש לפי מספר הזמנה, שם לקוח או מדור, לסנן לפי סטטוס תשלום ולעדכן את הסטטוס ישירות בטבלה.
6. למחיקת הזמנה לחצו על × בשורה ואשרו את הפעולה.

לחלופין, מתוך תיקיית הפרויקט אפשר להפעיל שרת מקומי באמצעות `python -m http.server 8000` ולפתוח `http://localhost:8000`. אם קובץ ה־HTML נפתח ישירות, חלק מהדפדפנים עשויים להגביל אחסון מקומי; במקרה כזה מומלץ להשתמש בשרת המקומי.

לניקוי הנתונים, מחקו את נתוני האתר/האחסון המקומי של הדפדפן עבור האתר. נתוני הדגמה לא יופיעו שוב כל עוד נשאר ערך שמור.
