# בדיקה מול פרויקט Supabase נפרד (לא הייצור)

**המטרה:** לבדוק מול Supabase אמיתי את מה שהגרסה המקומית לא יכולה לבדוק:
- התחברות אמיתית.
- Realtime בין שני מחשבים.
- מגבלות קצב.
- ביצועים ברשת.

הכול נעשה בפרויקט **חדש וריק**. הפרויקט הקיים (`orders`, `sndaeogseawtwzwxiqst`) לא נוגעים בו.

## הקמה, פעם אחת (כ-10 דקות)
1. **יוצרים פרויקט.** ב-Supabase יוצרים פרויקט חדש בשם ברור, למשל `hapirsumon-test`, ורושמים את מזהה הפרויקט (Project ref).
2. **מגדירים התחברות.** ב-Authentication:
   - מכבים הרשמה ציבורית.
   - מזמינים משתמש בדיקה עם כתובת דוא"ל שלך, לא של לקוח.
3. **מתקינים.** ב-**SQL Editor של פרויקט הבדיקה** מדביקים ומריצים את `testing/supabase-test/install-test-project.sql`. זו הרצה אחת שמתקינה את כל הקבצים בסדר המתוכנן לייצור.
   - **אם הפרויקט לא ריק,** הקובץ נעצר בלי לשנות דבר. לכן הוא לא יכול לרוץ בייצור.
4. **מאמתים.** באותו SQL Editor מריצים את `supabase-orders-v3-verify.sql` ואת `supabase-sheets-v2-verify.sql`. לא אמורה להופיע אף שורת `FAIL`.
5. **מאשרים את משתמש הבדיקה.** מחליפים את כתובת הדוא"ל:
   ```sql
   insert into private.approved_users (user_id)
   select id from auth.users where email = 'YOUR-TEST-USER@example.com';
   ```
6. **ממלאים את הגדרות החיבור.**
   - מעתיקים את `testing/supabase-test-config.example.json` אל `testing/supabase-test-config.json`. הקובץ מוחרג מ-Git.
   - ממלאים בו את ה-ref, את הכתובת ואת המפתח ה-**publishable** של פרויקט הבדיקה.
   - **אין להכניס מפתח secret או service_role.**

## הפעלה
```
node testing/local-pg/start-local.mjs --supabase-test
```
פותחים את http://127.0.0.1:8010/ ומתחברים עם משתמש הבדיקה.

**מה רץ כאן:**
- האתר האמיתי: אותם קבצים ואותה ספריית supabase-js עם SRI.
- הוא מחובר לפרויקט הבדיקה בלבד. פס כחול בתחתית מציג את מזהה הפרויקט.

**הגנות:**
- השרת מסרב לפעול אם בקובץ ההגדרות מופיע הפרויקט של הייצור.
- הוא מסרב גם אם הוכנס מפתח סודי.

## מה בודקים שם (קצר)
- **התחברות:**
  - משתמש מאושר נכנס.
  - משתמש שלא אושר נחסם.
  - התנתקות.
- **הזמנה:** הזמנה כספית והזמנה בקרדיטים, תקבול חלקי, ביטול, ועריכה בלחיצה כפולה.
- **חבילות:** רכישת חבילה, ועריכת לוח התשלומים.
- **גיליונות:** הוספה, וסגירה. הזמנה לגיליון סגור נדחית.
- **Realtime:** פותחים את האתר בשני מחשבים או בשני דפדפנים. שינוי בצד אחד מופיע בצד השני בתוך שניות.

## לעדכן את קובץ ההתקנה אחרי שינוי ב-SQL
```
node testing/supabase-test/build-bundle.mjs
```
בדיקת הרגרסיה מריצה את הפקודה עם `--check`, ונכשלת אם הקובץ לא תואם לקובצי ה-SQL.
